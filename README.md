# Task 15 – Pandas DataFrame Basics

## Veda Technology Data Science Internship

### Objective
Learn how to create and explore Pandas DataFrames using Python.

### Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook / Google Colab

### Programs Completed

1. Creating a DataFrame manually using dictionaries.
2. Displaying the first five rows using `head()`.
3. Finding the number of rows and columns using `shape`.
4. Displaying column names using `columns`.
5. Checking data types using `dtypes`.
6. Exploring dataset information using `info()`.
7. Generating summary statistics using `describe()`.
8. Loading the Iris dataset into a DataFrame.
9. Exploring the Iris dataset.
10. Selecting specific rows and columns.
11. Checking missing values using `isnull()`.
12. Counting species using `value_counts()`.

### Dataset
Iris Dataset – A commonly used dataset containing 150 flower records and four numerical features.

### Key Learnings
- Understanding Pandas DataFrames.
- Creating DataFrames from dictionaries.
- Loading real-world datasets.
- Exploring rows and columns.
- Understanding data types.
- Generating statistical summaries.
- Performing basic data analysis.

Successfully completed Task 15 and learned the fundamentals of Pandas DataFrames and dataset exploration.
